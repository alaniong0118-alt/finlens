### Astra remediation decisions and validation — 2026-10-13

All three findings were confirmed without expanding product scope. The ignored-abort predicate compared a short company path against a production-prefixed pathname; the selected path now normalizes to `/api/finlens/companies/...` and matches same-origin requests only. The self-contained callback is serialized in a VM to reproduce addInitScript execution without closures. Named delivery proofs now bind to the originating pin, query and status and require the original production signal to be aborted. Real API-client regressions prove an active 409 still invalidates, while a cancelled request cannot invalidate; publication 0 remains valid. Existing pre-commit React/StrictMode races are untouched and passing.

The old launcher skipped termination after ChildProcess leader exit. OwnedProcessGroup now uses Linux `/proc` group/session membership and leader start time, with independent ownership captured after detached spawn. SIGTERM waits at most five seconds before SIGKILL, followed by a five-second verification deadline. Cleanup checks absence of running members again before deleting the verified owned directory. Exited zombies do not hold files; any unverifiable ownership/termination retains files. Shutdown calls coalesce, and the deny-all listener closes even on termination failure. Non-Linux browser execution is refused before temporary-copy creation. Eight injected offline cases cover normal shutdown, dead leader, TERM resistance, concurrent failure cleanup, verification failure, changed session/PID reuse and zombies. Four real detached Linux process-tree tests assert termination before deletion and survival of an unrelated control group; the TERM-resistance case requires actual SIGKILL. Linux execution is pending, never represented by portable passes.

Test-only observations now vary by company, period and year: annual AAA/BBB 2025 = $5B/$9B, 2024 = $4B/$7B; AAA direct-quarter/half-year/nine-month = $1B/$2.4B/$3.7B. Selected histories contain unavailable 2023, zero 2024 and current 2025 points. Assertions require exact interval dates and displayed values, including comparison year round-trip. Actual production annual/evidence validation rejects deliberately mismatched identities, periods and missing metrics. No production calculations/contracts were modified.
